## Utilização Bootstrap

Utilizamos [Bootstrap](https://getbootstrap.com.br/) **versão 4.1** como esqueleto para gerenciamento de layouts responsivos através de seu `grid layout`, assim, como alguns de 
seus componentes pré-construídos.

### Componentes utilizados

- Accordion
- Bar Progress
- Buttons
- Breadcrumb
- Dropdown
- Forms
  - Checkbox 
  - Input
  - Radio
  - Textarea

### Classes de controle de layout

- container
- container-fluid
- row
- col (sm/md/lg)
- forms
  - form-row
  - form-group
  - form-control

### Classes de controle de estilos

- border (top/rounded/etc...)
- display (d-none/d-flex/etc..)
- float (left/right/etc...)
- margin (top/left/etc...)
- padding (top/letf/etc...)
- text (center/danger/etc...)

> Realizar leitura do nosso [style guide](https://gitlab.com/ekaizen1/ekaizen-frontend-redo/-/blob/develop/README.md) para uma melhor entendimento e implementação do Bootstrap.
